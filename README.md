# Knowledge Lab

A structured, automated repository dedicated to accumulating and organizing architectural knowledge, starting with Autodesk Revit.

## Overview

This repository is designed to serve as a comprehensive learning and reference environment for architecture studies. It leverages AI agents, web extraction tools (like Firecrawl), and context processors (like Context7) to systematically build a high-fidelity documentation hub.

## Structure

- **[docs](./docs/README.md)**: The central repository for all gathered documentation.
  - **[revit](./docs/revit/README.md)**: Dedicated hub for Autodesk Revit materials, workflows, and technical references.
- **[.agents](./.agents/README.md)**: Contains agent skills, automated workflows, and the `plans` directory where execution and study plans are authored.

## Getting Started

To interact with Knowledge Lab or add new study plans, refer to the [plans directory](./.agents/plans/).
For agent context and operational rules, refer to the [Root Agent Context](./AGENTS.md).
